## How to read this site

Every HTML page has a Markdown twin at `<page-url>index.md` and a JSON twin at `<page-url>index.json`. The links below point at the Markdown versions; drop the trailing `index.md` for the HTML page. All endpoints are static, need no API key, and are served with permissive CORS.

- [llms-full.txt]({{ "llms-full.txt" | absURL }}): the whole site as one Markdown document
- [For AI agents & tools]({{ "ai/index.md" | absURL }}): guide to every machine-readable endpoint
- [OpenAPI description]({{ "openapi.json" | absURL }}): the read-only endpoints as an OpenAPI 3.1 document, ready for tool/function definitions
- [Profile (JSON)]({{ "about/index.json" | absURL }}): structured profile under `data` — roles, experience, education, certifications, patents, memberships, links
- [Talks (JSON)]({{ "talks/index.json" | absURL }}): every talk under `data` — year, title, event, location, type
- [Publications (JSON)]({{ "publications/index.json" | absURL }}): articles and books under `data`
- [Blog index (JSON)]({{ "posts/index.json" | absURL }}): every post with metadata and links to its Markdown and JSON
- [JSON Feed]({{ "feed.json" | absURL }}): all posts with full HTML and plain-text content (JSON Feed 1.1)
- [RSS]({{ "index.xml" | absURL }}), [Sitemap]({{ "sitemap.xml" | absURL }}), [Search index (JSON)]({{ "index.json" | absURL }})
